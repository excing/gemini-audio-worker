## 原型

菜单(侧边栏)
 - 顶部: Logo + 产品名: BingwuAI 语音助手 + 收起按钮
 - 中间: 新聊天, 新角色, 角色列表
   - 角色列表
     - item, 线性布局, 居左(角色名称), 居右(打电话按钮 + 菜单按钮)
       - 菜单按钮(icon): 菜单有配置和删除按钮
         - 配置按钮, 点击打开角色配置模态框
         - 删除按钮, 点击删除该角色, 弹窗询问是否确认删除
           - 删除角色模态框
             - 如果用户正在连线该角色, 弹窗内应有明显的提示
             - 确认删除角色时, 如果正在连线, 则自动断开
     - 切换角色, 断开连接(如果有), 进入新聊天
 - 底部: 深浅色模式切换, 设置按钮
   - 设置按钮(icon), 点击打开系统配置模态框
   - 深浅色模式切换(icon), 支持三种模式, 深色, 浅色, 和跟随系统, 默认跟随系统
聊天模式
 - 标题栏(页面顶部, 线性布局: 居右(菜单按钮), 居中(状态+标题), 居右(打电话, 自动朗读开关))
  - 菜单按钮(icon), 点击显示和隐藏菜单组件
  - 状态, 圆点显示, 表示当前会话状态, 默认状态不显示, 绿色表示已连接, 黄色表示连接中, 红色表示已断开
  - 标题,  默认显示”BingwuAI 语音助手“, 当开始聊天时, 显示角色名称, 超出宽度, 省略显示..., 点击角色名称, 可打开角色配置模态框
  - 打电话按钮(icon), 进入打电话模式
  - 自动朗读开关(icon), 打开或关闭AI自动朗读
 - 消息列表
   - 用户消息(居右)
    - 文本消息
    - 语音消息, 可重复播放
   - AI 消息(居左)
    - 语音 + 文本, 文本参考“AI 文本逐字显示”一节, 语音可重复播放.
   - 系统消息(居左)
    - serverContent 相关业务
   - 系统状态(居中)
    - 连接状态, 错误信息等, 居中小字显示
 - 消息输入 (页面底部, 线性布局: 居左(打电话), 居中(消息主区域), 居右(切换按钮))
   - 打电话按钮(icon), 进入打电话模式
   - 切换按钮(icon): 语音输入 or 文本输入 or 发送按钮
    - 发送按钮, 发送文本输入框内容, 仅当文本输入框有内容时显示
   - 消息主区域
    - 长按录音按钮, 占满整个主区域, 松手即发送, 语音输入时显示
    - 文本输入框, 占满整个主区域, 文本输入时显示, 当文本框里有内容时, 切换按钮变为发送按钮
      - 自动增高
      - 最大 5 行
打电话模式(全程打开麦克风, WS连接断开则自动退出)
 - 标题栏(页面顶部, 线性布局: 居左(取消通话按钮), 居中(角色名称), 居右(字幕开关))
   - 角色名称, 不可点击, 超出宽度, 省略显示...
   - 字幕开关(icon), 显示或隐藏当前最新消息
 - 主区域(两层设计, 底层(通话模式图像)+上层(字幕))
   - 底层(所有UI居中显示)
     - 默认模式, AI 说话时显示波形动画
     - 视频模式, 显示当前摄像头画面, 居中, 100%显示
       - 视频画面位于 call-stage 的 wave 和 caption-overlay 的中间, 铺满
       - 视频帧始终发送, 不受“静音按钮”的模式影响
     - 投屏模式, 显示退出投屏按钮
       - 投屏画面位于 call-stage 的 wave 和 caption-overlay 的中间, 铺满
       - 投屏画面仅居中显示“退出投屏按钮”, 不显示当前屏幕画面
       - 投屏帧始终发送, 不受“静音按钮”的模式影响
   - 上层, 字幕, 显示最新消息, 主区域遮盖层, 半透明背景
     - 显示主区域左上角, 居左
     - 文本列表, 仅显示最新的4条消息, 颜色偏淡
       - 用户消息, 透明度降低
       - AI 消息, 参考“AI 文本逐字显示”一节
 - 状态区
  - 状态按钮(icon)
    - 当 AI 正在连接时, 显示停止按钮, 点击时取消连接
    - 当 AI 输出时, 显示停止按钮, 点击时停止 AI 输出
    - 当 AI 输出完成时
      - 处于非静音或轮询时, 显示录音状态按钮, 带波形动画效果, 禁止点击
      - 处于静音时, 显示为静音 icon
  - 状态提示文案
    - 当 AI 正在连接时
      - 显示“正在连接中...”
    - 当 AI 输出时
      - 处于非静音时, 显示“说话或点击打断”
      - 处于静音或轮询时, 显示“点击打断”
    - 当 AI 输出完成时
      - 处于非静音或轮询时, 显示“正在听...”
      - 处于静音时, 显示“已静音”
 - 操作区(页面底部, 线性布局, 各按钮平分布局)
  - 静音按钮(icon)
    - 三种模式, 非静音, 静音, 和轮询
      - 非静音, 又称自由模式, 即实时双向语音会话
      - 静音, 停止发送录音音频, AI单向语音会话
      - 轮询, 又称自动模式, 由会话状态决定是否发送录音音频, 当 AI 输出时, 不发送, 当 AI 输出完成时, 发送.
    - 静音按钮的状态与状态区的状态需保持一致
  - 屏幕分享(icon), 打开或关闭屏幕分享
    - 每一秒时间发送一频图片(参考: https://ai.google.dev/gemini-api/docs/live-api/capabilities?hl=zh-cn#send-video)
  - 视频按钮(icon), 打开或关闭摄像头
    - 每一秒时间发送一频图片(参考: https://ai.google.dev/gemini-api/docs/live-api/capabilities?hl=zh-cn#send-video)
  - 取消通话按钮(icon), 退出打电话模式, 进入聊天模式

AI 文本逐字显示
 - 行为, 跟随语音进度, 未播放部分：透明度降低, 已播放部分: 高亮

创建会话连接
  - 进入一个新聊天(会话)时, 默认不连接WS.
  - 当用户发送第一条消息时(文本/音频/视频), 自动连接, 连接成功后, 发送第一条消息
  - 当用户未连接时, 进入打电话模式, 自动连接

更新角色配置
  - 如果该角色为系统默认角色, 更新时, 创建为新角色, 角色名后添加`(自定义)`文本

页面整体布局
  - Desktop
    - 侧边栏显示或隐藏
    - 默认显示, 可点击菜单/收起隐藏
    - 宽度: 320px
  - Tablet
    - 侧边栏抽屉化
    - 默认隐藏
    - 宽度: 280px
  - Mobile(全屏沉浸式)
    - 顶栏缩小
    - 按钮增大
    - 安全区适配
    - 宽度: 全屏抽屉

模态框
  - 角色配置模态框(模态框标题: 角色配置)
    - 角色名
    - 模型
    - 语音
    - 系统提示词
    - 自动加载工具
    - 工具快捷选择(刷新 + 全部 + 清空)
      - 支持的工具列表
    - 取消 + 保存
  - 系统配置(模态框标题: 系统配置)
    - 深色浅色模型切换, 支持跟随系统

角色数据结构
  - `id`, `name`, `model`, `voiceName`, `systemInstruction`, `autoLoadTools` 见上面 UI 字段.
  - `mcpServers`: array, 每项 `{ name, url, headers? }`. 由前端的 `public/mcp-client.js` 在每次连接时拉 `tools/list`, 把发现的 MCP 工具与前端内置 browser 工具合并, 一同进入 `autoLoadTools` 候选集. 暂无 UI 编辑器, 通过 `public/constant.js` 默认值或 localStorage 直接维护.
  - `autoLoadTools` 中写裸 `<server-name>` (例如 `mcp1`) 等价于启用该 server 下所有 `mcp1__*` 工具 — 前端在发送 setup 前完成前缀展开.

其他
  - 使用系统自带的字体, 不额外引用外部字体
  - 使用 Lucide Icons: https://unpkg.com/lucide@1.16.0/dist/umd/lucide.min.js

## UX

聊天模式
  - 聊天不自动启动麦克风
  - 当用户按住说话时, 启动麦克风说话, 当用户松开时, 关闭麦克风
  - 用户按住说话时, 麦克风不会被其他事件打断
打电话模式
  - 全程开启麦克风
  - 静音模式, 不发送音频数据
  - 非静音模式(自由模式), 实时发送音频数据
  - 轮询模式(自动模式), 当 AI 说话结束时, 开始发送音频数据, 当 AI 开始说话时, 不发送音频数据
  - 注意: 这三种模式只是开关音频数据是否发送
  - 挂断时, 关闭麦克风
  - 麦克风因意外或异常被关闭时, 自动挂断电话
麦克风开启和关闭
  - 只有两种情况
  - 1. 用户按住说话, 打开麦克风, 松开说话, 关闭麦克风
  - 2. 进入打电话模式, 自动打开麦克风, 挂断电话/或会话中断, 关闭麦克风
  - 不存在第三种情况
  - 也就是说, 麦克风状态与会话状态(除了会话异常中断)没有任何关系

## UI

1. 设计风格 (Design Aesthetics)
 - **高级极简 (Premium & Minimalist)**: 界面追求干净整洁, 采用无边框设计 (Border-less design), 减少视觉噪音. 尽可能通过背景色或间距区分层级，极少使用明显的实线边框。
 - **动态感 (Dynamic)**: 广泛应用微动画 (Micro-animations) 和过渡效果 (Transitions), 如元素的显隐, 尺寸渐变等, 使界面具备生命力.
 - **毛玻璃效果 (Glassmorphism)**: 侧边栏, 模态框, 悬浮按钮和打电话模式的字幕条等需使用背景模糊效果 (`backdrop-filter: blur(12px) saturate(180%)`), 配合半透明背景色 (如 `rgba(255, 255, 255, 0.7)` 或 `rgba(9, 9, 11, 0.7)`), 增加空间层次感.

2. 主题与配色 (Themes & Colors)
 - **全面支持深浅色模式 (Dark/Light Mode)**: 提供深色、浅色以及跟随系统三种模式切换.
 - **极简配色**: 
   - 浅色模式: 背景色纯白 `#FFFFFF` 或 极浅灰 `#F9FAFB`；主文本深灰 `#111827`；次文本中灰 `#6B7280`；边框与分割线浅灰 `#E5E7EB`；悬浮背景色 `#F3F4F6`；模态框遮罩 `rgba(0, 0, 0, 0.4)`。保证干净通透。
   - 深色模式: 背景色纯黑 `#000000` 或 深灰 `#09090B`；主文本近白 `#FAFAFA`；次文本浅灰 `#A1A1AA`；边框与分割线暗灰 `#27272A`；悬浮背景色 `#18181B`；模态框遮罩 `rgba(0, 0, 0, 0.6)`。
 - **渐变色限制**: 根据总体原则, 除“打断/发音波形动画”, “系统消息块”或特定的主按钮允许使用低调高级的渐变色外, 绝大部分元素严格使用纯色.
 - **功能色 (Functional)**:
   - 警告/危险操作 (Danger): 红色 `#EF4444` (用于删除等确认)
   - 成功/连接态 (Success): 绿色 `#10B981` (状态圆点)
   - 提示/连接中 (Warning): 黄色 `#F59E0B` (状态圆点)

3. 排版与字体 (Typography)
 - **现代系统字体 (System Fonts)**: 严格使用系统自带的现代无衬线字体 (`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`), 不额外引用外部字体以保障极致加载性能.
 - **清晰层级**: 标题 (Title), 副标题 (Subtitle), 正文 (Body) 和辅助说明文字 (Caption) 需要有明确的大小 (font-size), 字重 (font-weight) 和颜色层级区分.
   - 标题 (H1 / Modal Title): `20px` (Font-weight: 600)
   - 副标题 (H2 / Section Title): `16px` (Font-weight: 600)
   - 主正文 (Body / Chat Text): `14px` 或 `15px`, 行高 `1.5` (Font-weight: 400)
   - 辅助文本 (Caption / Time): `12px` (Font-weight: 400 或 500)
   - 表单控件 input / textarea / select 最小字号为 16px，用于避免 iOS Safari 聚焦自动缩放；这不改变正文 14px/15px 的层级规范。

4. 尺寸与间距 (Spacing & Sizing)
  - **内外间距 (Padding & Margin)**:
    - 基础间距步长: `4px`
    - 元素内边距 (Button Padding): `8px 12px`
    - 容器内边距 (Container Padding): `16px` 或 `24px`
    - 消息气泡间距: `16px`

5. 交互与微动画 (Micro-Interactions)
 - **悬停与点击 (Hover & Active)**: 所有可点击的图标和按钮必须有平滑的反馈效果。全局过渡动画 `transition: all 0.2s ease-in-out`；按下反馈 `transform: scale(0.97)`。
 - **波形动画 (Waveform)**: 录音和 AI 讲话时, 需提供平滑, 流畅的实时音频可视化动画, 作为语音的动态反馈。(需使用 Canvas 或 CSS 动画达到至少 60fps 刷新率)
 - **逐字显示 (Text-reveal)**: AI 语音对应的文本应有逐字高亮的过渡动画。未播放部分降低透明度 (`opacity: 0.5`)，已播放部分高亮显示加粗 (`opacity: 1`)。
 - **平滑过渡与模态交互**: 所有的模式切换, 组件显示/隐藏以及**模态框 (Modal)** 的弹出和关闭, 都必须配合贝塞尔曲线过渡动画 (`ease-in-out`)。弹窗动画推荐使用 `transform: scale(0.95)` 至 `scale(1)` 配合 `opacity` 渐变。
 - **危险操作警示**: 删除角色等破坏性操作需弹出确认模态框, 如果该角色正处于连接状态, 必须在弹窗中以醒目的样式 (如警告色 `#EF4444` 或高亮文本) 提示用户.

6. 图标与控件 (Icons & Components)
 - **统一图标库**: 强制统一使用 **Lucide Icons** 构建界面图标, 保持极简, 线性, 粗细一致且圆润的视觉效果。
   - 常规图标 (Menu/Settings): `20px` 或 `24px`
   - 按钮内部图标: `16px`
 - **圆角设计 (Border Radius)**: 按钮, 卡片, 模态框, 输入框均采用现代感的适中圆角。
   - 图标按钮/标签 (Pill shape): `9999px` (全圆角)
   - 普通按钮/输入框 (Inputs/Buttons): `8px`
   - 卡片/聊天气泡 (Cards/Bubbles): `12px`
   - 模态框 (Modals): `16px`
 - **输入框自适应**: 聊天底部的文本输入框需平滑地自动增高 (配合 `transition`), 最大高度限制为 5 行, 超出则内部滚动.

7. 响应式与跨平台适配 (Responsiveness)
 - **Desktop (宽屏)**: 侧边栏常驻, 可点击收起和展开, 宽度 `320px`。留白充足, 视觉焦点集中在聊天主体。
 - **Tablet (平板)**: 侧边栏自动转为抽屉模式 (Drawer), 宽度 `280px`。释放屏幕空间。
 - **Mobile (移动端)**: 深度优化安全区 (Safe Area), 增大触控目标 (至少宽/高 `44px`), 实现全屏沉浸式体验, 顶栏与底栏(高度 `60px/64px`)操作区紧凑布局。
