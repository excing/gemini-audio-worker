# 修改日志

日期: 2026-05-19

起始提交: `98f7b75` (Refine call audio handling and add change log)

## 本次变更概览

本次变更覆盖了通话模式打磨、字幕区重设计、音频模块抽离，以及前端权限/异常 UX 的整体加固，并引入 `vue-sonner` 作为统一 toast 提示组件。

## 详细修改

### 1. 通话模式打磨 (2ce9e29 / 0deaa29 / d2adcae)

- 新增 `callTurnOwner` 状态，区分用户/模型当前的发言权，在 `turn` 模式下基于发言权决定是否发送麦克风音频。
- 引入 `playReadyTone` 提示音：会话就绪、模型发言结束时播放上升音调，提示用户可以开口。
- 自动朗读开关由“硬停”改为通过 `GainNode` 平滑过渡，避免切换时音频被生硬截断；所有 AI 音频均路由经过统一的 `playbackGain`。
- 自动朗读开关在连接过程中也可以切换，只在麦克风启动瞬间禁用，避免连接态下用户无法预先调音量。
- 删除未使用的 `public/speech_start.mp3`。

### 2. 字幕区重设计 (9bc068b / 4d18c27)

- 通话字幕浮层改为全舞台覆盖，内容区限制为 70% 宽高的可滚动区域，背景透明，浮层本身不拦截事件。
- 字幕新增自动滚动：消息追加或字幕开关切换时自动滚到底部，滚动条隐藏。
- 移除字幕行的角色标签，简化视觉，保留对齐方式区分用户/模型。
- 消息角色标识统一为英文 (`user` / `system` / `Gemini`)，CSS class 直接使用角色名，去除散落在模板里的中英文映射条件。

### 3. 音频模块抽离 (ddd6a46)

- 新建 `public/audio-service.js`，把 AudioContext 管理、PCM 播放、字幕调度、麦克风采集与重采样从 Vue 组件抽离为独立服务。
- 服务通过回调注入业务依赖 (`getVoiceEnabled` / `shouldSendAudio` / `canSendAudioInput` / `onAudioInput` / `onCaptionDue` / `onMicEnded`)，组件只负责 UI 状态。
- `index.html` 中保留的音频入口方法 (`ensureAudio`、`playPcm`、`startMic`、`stopMic`、`syncPlaybackVolume` 等) 全部转发到服务实例。

### 4. 麦克风权限与异常 UX 加固

- 新增 `audio-service.checkMicAvailable()` 前置检查：
  - 非安全上下文 (HTTP + 局域网 IP) 抛出 `InsecureContextError`。
  - 浏览器不支持 `getUserMedia` 时抛 `NotSupportedError`。
  - `navigator.permissions.query({ name: 'microphone' })` 返回 `denied` 时抛 `NotAllowedError`。
  - `enumerateDevices` 显示没有任何 `audioinput` 设备时抛 `NotFoundError`。
- `enterCallMode` 与 `startHoldRecord` 在调用前先走 `precheckMic()`：
  - 未通过：不进入通话模式、不发起 WebSocket 连接、不启动麦克风，直接 toast 报错。
  - `startHoldRecord` 在异步 precheck 期间若用户已松手，会自动放弃后续启动，避免竞态。
- `startMic` 失败回调改为通过 `showMicError` 区分提示：
  - 未授权 / 设备未找到 / 设备占用 / 不支持 / 非安全上下文 / 通用错误。

### 5. WebSocket 消息解析加固

- `ws.onmessage` 中的 `JSON.parse` 包裹 try/catch，解析失败仅 `console.warn` 记录并忽略，避免单条异常消息让整个应用崩溃。

### 6. 引入 vue-sonner toast 系统

- `index.html` 通过 importmap 引入 `vue-sonner`，注册全局 `<Toaster>` 组件 (位置 `top-right`，时长 3200ms，`rich-colors`、`close-button`)。
- toast 主题绑定到 `themeMode`，与“跟随系统/浅色/深色”三态保持一致。
- 关闭按钮通过 CSS 重定位到 toast 右上角:
  ```css
  [data-sonner-toaster] [data-sonner-toast] [data-close-button] {
    left:auto !important; right:0 !important;
    transform: translate(40%, -40%);
    width:28px; height:28px;
  }
  ```

## 风险提示

- `vue-sonner` 通过 esm.sh / unpkg CDN 加载，离线环境不可用，必要时需要本地化。
- 麦克风 precheck 中 `permissions.query({ name: 'microphone' })` 在部分 Firefox 版本不支持；当前逻辑会静默忽略并继续走 `getUserMedia`，依赖系统弹窗兜底，无回归风险，但需注意首次授权前 `enumerateDevices` 可能返回空 label。
- 非安全上下文检查依赖 `window.isSecureContext`，所有现代浏览器均支持，无需额外兜底。
